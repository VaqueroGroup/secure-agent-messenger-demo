OPERATOR

The chat that closes the loop.

The one that remembers · build demo
The conversation is the interface. He drops the invoice, the photo, the voice note — Operator reads them, finds the money, and hands back a decision. One tap closes the loop and files the evidence. Everything lands in the record.

TRY IT IN THE PHONE

  • Approve & send — the credit note goes out and the loop closes in the thread
  • View — the agent shows the matched line detail
  • 🔒 E2E LOCKED — flips the whole thread to what the server sees: ciphertext
  • Send a message from the field — the agent answers and diaries the chase

THE STACK UNDER IT

draft → encrypt (double ratchet) → serialize (protobuf) → WSS → server queues if offline → push (APNs / UnifiedPush) → recipient wakes → pull → decrypt locally server sees: ciphertext · timestamps · IP server never sees: content · contacts · files

WHY IT MATTERS

A tradie's message history is evidence. Payment fights, supplier credits, super disputes — on WhatsApp the record lives on someone else's server. Here it builds itself while he just texts, and the evidence pack is ready the day the fight starts.
